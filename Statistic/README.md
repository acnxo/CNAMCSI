# Statistic · 对比图与统计产物

本目录全部文件由 [`Compare.py`](../Compare.py) 生成，**请勿手工编辑**；
需要改图、改口径或改统计列，请修改 `Compare.py` 后重跑（见文末「重新生成」）。

三个业绩比较基准：`国证2000`（红）、`中证2000`（紫）、`中证全指`（青）。

## 二、图的构成

- **主图**：6 条净值曲线，以颜色区分（全部实线）；左上角图例同时给出各序列的末值；
- **回撤子图**：主图下方 6 个面板，每个序列一个，与主图共用同一时间轴；
  面板右侧标注 **最大回撤**（灰）与 **当前回撤**（系列颜色加粗，= 最新交易日相对历史峰值的跌幅）；
- **坐标轴自适应**：Y 轴按绘图区高度取 1/2/2.5/5×10ᵏ 的整齐步长；X 轴按季度（每年年初与
  3/6/9 月底）画淡色网格线——**年份多的图只保留网格线、不写月份文字**，跨度 ≤ 9 年时
  才在网格处标两位月份；**每年年初另有一条更明显的年份分界线**（逐年一条，不受文字抽稀影响），
  年份文字按 44px 间距抽稀（全时段图隔年标注）；回撤面板的百分比横线同样自适应；
- 画布为 1180px 宽的内容按 2 倍缩放（2360px 宽），纯手写 SVG，无脚本、无外部字体依赖。

## 三、口径

- **归一化**：图中每条序列在每个窗口内都以「该窗口的首个数据点 = 1000 点」重新折算，
  因此全时段图各序列的起点不同（可见图例与 `Comparison.md` 的「起点」列）：

  | 序列 | 全时段图起点 |
  | --- | --- |
  | CNAMCSDEWI / CNAMCSWEWI / CNAMCSMEWI | 2004-12-31 |
  | 中证全指 | 2004-12-31 |
  | 国证2000 | 2014-03-31 |
  | 中证2000 | 2023-08-11（发布日） |

- **区间收益**：末值 / 窗口首值 − 1；**年化**：按 252 交易日折算；
- **最大回撤**：窗口内相对历史峰值的最大跌幅（≤ 0）；
- **当前回撤**：窗口内最后一个交易日相对历史峰值的跌幅，即图上右侧彩色值，与最大回撤同一把尺子；
- `Comparison.md` 的表格与同窗口的图完全同口径，可对照图例末值逐行核对。

窗口起点随运行日滚动：`10Y/5Y/3Y/1Y` 分别由 `as_of` 向前推 10/5/3/1 年，
所以 `Comparison.md` 中每个窗口的「起点」列以当次生成为准。

## 四、数据来源

## 五、重新生成

```bash
python3 Compare.py             # 拉取基准（失败自动回退缓存）并重算全部图与统计
python3 Compare.py --no-fetch  # 离线：只用 Benchmarks/ 缓存
```

运行后覆盖本目录的 7 个 SVG、`Comparison.md`、`Comparison.json`（本 README 不受影响），
提交时 `git add Compare.py Statistic` 一并提交。
